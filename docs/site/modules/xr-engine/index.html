    xrEngine (ядро)¶

    xrEngine — ядро движка: CEngine, CSheduler, CRenderDevice, событийная шина, консоль, Lua-биндинг, камера/HUD, окружение, эффекты, ввод.

    См. Карта модулей, Цикл кадра, Модель объектов.

    Структура¶

    Страница Что покрывает
    Ядро (CEngine) и точка входа CEngine, PSGP, WinMain/WinMain_impl/Startup, CApplication, pure.h/CRegistrator, defines.h, CLSID
    API и события CEngineAPI (рендерер, игра, vTune, фабрика), CEventAPI/CEvent, KERNEL:*

    Sheduler CSheduler, ISheduled, Register/Unregister/EnsureOrder, адаптивный бюджет
    Device (порцион 3) — CRenderDevice, CRenderDeviceData, Device_create/Initialize/destroy, таймеры, матрицы
    Окно и WndProc (порцион 3) — Device_wndproc, Device_Misc, Device_overdraw, xrHemisphere

    Карта связей¶

    graph TD
    subgraph xrEngine
        Engine[CEngine]
        Event[CEventAPI]
        Sched[CSheduler]
        Device[CRenderDevice]
        App[CApplication pApp]
        Ext[CEngineAPI]
    end
    subgraph расширения
        Render[xrRender R?]
        Game[xrGame]
        Server[xrServer]
    end
    Engine --> Event
    Engine --> Sched
    Engine --> Ext
    Ext --> Render
    Ext --> Game
    Game --> Server
    App --> Event
    App --> Device
    Device --> Render
    Sched --> App
    Sched --> Game
    • CEngine — корень. Владельцы: Engine, pApp.
    • CEventAPI — шина KERNEL:* между xrGame/xrServer/консолью и CApplication/рендерером.
    • CSheduler — планировщик ISheduled (уровень, ALIFE, звук, …). Не путать с CRegistrator (упорядоченный список сообщений).
    • CRenderDevice — устройство + окно + матрицы + таймеры. Поднимается через Device.Create/Initialize/Run.
    • CApplication — «приложение» на уровне процесса: уровень, шрифт, загрузка, Discord.
